STFM-FNO

Spatio-Temporal Field-Modulated Fourier Neural Operator for Transmission Loss Estimation

Yufei Yang, Yifan Sun, Lei Cheng, and Peter Gerstoft
IEEE Signal Processing Letters · Early Access
Code IEEE Xplore Results Getting Started

Estimate transmission loss at the same time as the input sound speed field, using time-conditioned modulation of latent spatial features.

Overview

STFM-FNO is a learned surrogate for ocean acoustic transmission loss (TL) estimation. It takes a sound speed field (SSF), range-depth coordinates, and the associated time and estimates TL at the same locations and time.

The method maps Fourier-encoded time to block-wise affine parameters that modulate latent spatial features. The study evaluates this design under monthly blocked testing with temporal purge intervals, including conditional FNO baselines, a separate operating-frequency experiment, and alternative temporal encodings.

Problem and Role of Time

With source and boundary conditions fixed, the SSF determines TL through a physical mapping. The time-conditioned surrogate uses temporal structure in the environmental dataset as an auxiliary inductive bias.

The input consists of the SSF across range and depth, the locations of these points, and the time at which the SSF was collected. The output is TL at the same ranges and depths at that time. Time acts as an auxiliary conditioning variable.

Method

Two Branches, Block-wise Conditioning

The spatial branch lifts the SSF and its coordinates to a latent tensor and processes it through four FNO blocks. The temporal branch maps the time index to a Fourier descriptor and generates affine modulation parameters for each block. Spatial convolution parameters remain shared across time, while each block learns a temporal response appropriate to its feature representation.

Daily and Yearly Fourier Encoding

Daily and yearly periods provide physically motivated time scales. Sine-cosine pairs preserve phase continuity across cycle boundaries, while multiple harmonics enrich the representation of within-cycle variation.

\[ \phi(t) = \left[ \left(\sin\left(2\pi k t/N_d\right),\cos\left(2\pi k t/N_d\right)\right)_{k=1}^{K_d}, \left(\sin\left(2\pi k t/N_y\right),\cos\left(2\pi k t/N_y\right)\right)_{k=1}^{K_y} \right]. \]

With \(N_d=8\), \(N_y=2920\), \(K_d=4\), and \(K_y=8\), the descriptor has 24 channels: eight daily and sixteen yearly components.

Spatio-Temporal Field Modulation

A block-specific temporal MLP produces channel-wise parameters \(\gamma_\ell(t)\) and \(\beta_\ell(t)\). For the spatial feature tensor \(\widehat{\mathcal F}_\ell(\mathbf{x})\), the additive latent modulation field is

\[ \mathcal M_\ell(\mathbf{x},t) = \gamma_\ell(t)\odot \widehat{\mathcal F}_\ell(\mathbf{x})+\beta_\ell(t). \]

The scale reweights channels and the shift adjusts their baselines. Each parameter is shared over the spatial grid, but its action on spatially varying features creates a spatially varying latent modulation field. In the first block, these features reflect the SSF structure; deeper features also carry information from previous modulations.

Training and Inference

The surrogate is trained against RAM-computed TL fields, with input and output normalization based only on training data. At inference, the SSF, coordinates, and associated time yield a TL estimate in one forward pass.

Experiments and Results

Monthly Blocked Evaluation

The dataset contains 2,920 SSF snapshots over one year, sampled eight times per day. A central continuous test block is selected within each month. One-day intervals on either side are excluded from training and testing, reducing temporal leakage from highly correlated neighboring SSFs. The split contains 2,144 training, 584 test, and 192 purged samples.

The main configuration uses a 200-Hz source at 50-m depth and a 199-by-800 grid covering ranges of 0-40 km and depths of 0-200 m. The following tables show the results reported in the paper.

Operating-Frequency Change

Both Baseline FNO and STFM-FNO are retrained on the 100-Hz dataset using the same splitting and training settings. Their RMSEs are 2.27 and 2.12 dB, respectively. This experiment evaluates the method in another frequency configuration, not zero-shot transfer of a model trained at 200 Hz.

Alternative Temporal Encodings

The ablation compares generic fixed frequencies, learned frequencies, and prescribed daily/yearly time scales while holding the architecture and splitting strategy fixed. RMSE is averaged over three runs.

First-block Feature Interception

To show the temporal branch's direct effect, the study compares first-block features for the same held-out SSF at winter and summer time indices. The pre-modulation features remain similar, whereas the modulated features change with the supplied time. This is a model-level probe of learned temporal conditioning.

Code and Getting Started

The official implementation includes STFM-FNO, the comparison models, and temporal encodings used in the paper. Training and evaluation use the paper's monthly blocked split and experimental settings.

See the README for installation, the data specification for the required SSP/TL files, and the training and evaluation guide for experiment commands. The dataset and trained checkpoints are not bundled.
